# Gateway fabrication and assembly gates

From the repository root, run `sh tools/bundle-jlcpcb.sh [version] [--output-dir directory] [--smd-only]`. The default version is the highest numeric MAJOR.MINOR.PATCH directory under `electronics/boards/gateway/`. The script exports fresh Gerbers, separate PTH/NPTH drills, BOM and positions from the saved commercial native CAD using KiCad 10 and Python 3. Outputs default to workspace `.research/jlcpcb/gateway-<version>-gerbers.zip`, `-bom.csv` and `-cpl.csv`; custom output paths are relative to the caller. The Gerber ZIP contains only layers and drills; upload BOM/CPL separately for assembly.

The BOM groups exact value/package/MPN/catalog matches and preserves manufacturer part numbers. Optional schematic `LCSC` or `JLCPCB` fields supply catalog numbers; blank catalog numbers require matching the exact MPN in JLCPCB. The BOM and CPL use the same populated component set, excluding mounting holes, schematic BOM exclusions and DNP/position-file exclusions. Through-hole parts are included by default; `--smd-only` selects footprints marked SMD and adds `-smd` to output filenames. Coordinates retain KiCad’s absolute origin, in mm with positive Y upwards, matching the Gerber/drill export origin. Rotation is KiCad’s footprint rotation normalized to 0–360 degrees; no guessed component-specific correction is applied. Verify exact part matches, polarity, pin 1 and top/bottom orientation in JLCPCB’s assembly preview.

The script does not refill zones, run ERC/DRC, change source files or approve manufacture; complete the fabrication checks before ordering.

The manufacturing files in `fabrication/` are review exports from the matching native CAD. `SHA256SUMS.txt` records native sources and exports; run `shasum -a 256 -c fabrication/SHA256SUMS.txt` from this revision directory to verify the package. The prototype has not been approved for ordering and must not be described as fabrication-ready merely because ERC/DRC pass. Regenerate exports with `sh tools/check-and-export.sh 0.1.0` from the repository root after any CAD edit and inspect all copper, mask, paste, silk, edge and drill files together.

Use four copper layers, 1.6 mm nominal finished thickness, lead-free assembly and a fabricator-approved stackup matching the retained USB construction. The inherited USB calculation uses JLC04161H-7628 L1–L2 geometry, 0.2474 mm main pair width / 0.1501 mm edge gap. Request 90 Ω differential ±10% controlled fabrication and a coupon/TDR record. Ask the fabricator to approve actual copper weight, dielectric thickness/material, plated slots, all holes, mask, castellations/edge constraints and the retained 0.15 mm USB geometry clearance. L2 must remain continuously grounded beneath USB; L3 includes power/signal branches and is not an uninterrupted reference substitute.

The barrel connector uses three plated oblong slots derived from the current PJ-102AH drawing. Contact lands and slot dimensions must be checked with a purchased sample and fabricator. J2/J3 need four plated 0.90 mm finished contact holes and two 3.20 mm unplated locating holes each. Verify 1:1 paper or film overlays against actual USB, modular and barrel connectors before ordering. Check nose alignment, plug/latch access, mounting holes, panel thickness, body height and RECOM clearance in the enclosure. The positions CSV includes through-hole and mechanical features; filter these for pick-and-place and do not interpret it as a complete assembly instruction.

Before a production release, assemble a current-limited prototype and record rails, reverse polarity, all supply combinations, leakage into USB, regulator/fuse/diode temperatures, actual cable loss/temperature, termination, CAN FD error rates and recovery, USB orientations and OS enumeration. Perform ESD/transient/hot-plug and suspend-current qualification if required for the intended product. The D7 24.4 V nominal clamp point and F2 rating are component parameters, not verified system surge protection or sustained-overvoltage shutdown.

Power down before connecting unqualified cables. Never attach powered 4P4C sockets to handset/telephone equipment. A standard coiled handset cord is commonly reversed and does not establish a straight-through CAN twisted-pair cable.
