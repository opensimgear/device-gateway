The native 4P4C footprint is `OpenSimGear.pretty/RJ4P4C_Evercom_5301-4P4C_Horizontal.kicad_mod`. Its pad numbers come from the component-side primary drawing; do not reverse them using a plug-view sketch. On this PCB both sockets rotate 90° clockwise in KiCad, with mouths facing the east edge. Actual board pad numbers remain 1 BUS_12V, 2 CAN_H, 3 CAN_L, 4 GND. Review the numbered native pads or a 1:1 plot when defining a cable tester.

To migrate another board, run `python3 tools/install-4p4c-footprint.py /absolute/path/to/its/revision` to copy this footprint into its project-local OpenSimGear library, replace the socket symbol with four pins, explicitly reconnect all four net assignments, then update PCB placement and routing. A six-contact footprint cannot safely be changed by deleting its outer contacts: body, locating holes, stagger, pitch, numbering and electrical assignment differ. Regenerate the netlist, run schematic parity/ERC/DRC, and requalify purchased plugs and straight-through cable continuity. The separate module migration is outside this gateway revision.

The upstream footprint library license is retained in [LICENSE-KICAD.md](LICENSE-KICAD.md). The Evercom footprint is derived from KiCad's `RJ9_Evercom_5301-440xxx_Horizontal`, with the current 18.05 mm body depth, local MPN/description, reference on F.Fab and no unverified 3D model. Other unused copied library entries are not part of the BOM.
