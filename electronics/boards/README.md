# Gateway boards

- [Gateway v0.1.0](gateway/0.1.0/README.md): current native KiCad schematic and four-layer routed prototype, STM32G0B1CBT6, USB-C, two parallel 4P4C CAN/power jacks and 12 V center-positive barrel socket.

Use the schematic, PCB, BOM and manufacturing exports from the same version. The current design is work in progress and requires physical and fabricator checks before release. [PCB versioning](../VERSIONING.md) defines semantic versions and freezes 0.1.0 until launch.
