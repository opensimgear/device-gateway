# Gateway Cyphal/CAN test peer

`can_peer.py` implements a generic module peer for the active
[Cyphal/CAN application contract](../firmware/docs/cyphal.md). Its ctypes bridge
links the same generated DSDL and pinned libcanard transport used by the firmware.
Python contains the SocketCAN adapter and peer behavior; wire framing, transfer
IDs, node-ID collision handling, Heartbeat and GetInfo run in the native library.

Build the native target first with a C11 compiler and CMake. From the gateway
repository root:

```sh
cmake -S firmware -B .build/native -DOSG_BUILD_BOARD=OFF
cmake --build .build/native --parallel
python3 tools/can_peer.py --vectors
OSG_GATEWAY_TEST=.build/native/osg_gateway_test \
  python3 -m unittest discover -s tools -p 'test_*.py' -v
```

Python 3.10+ is sufficient once the shared library is built. Library discovery
checks the repository `.build/native`
directory. Use `--library /absolute/path/libosg_gateway_peer.so` or
`OSG_CYPHAL_PEER_LIBRARY` for another build location; macOS builds use `.dylib`.
`--vectors` prints actual Cyphal frames generated by that stack on any host.
The historical private CAN FD vector files are retained as archived fixtures.

For physical testing, use a Linux SocketCAN adapter configured for **500,000 bit/s
arbitration, 2,000,000 bit/s data and FD enabled**. The gateway uses a shared ground
and one linear bus with exactly two 120 Ω endpoint terminators. Consult the PCB
wiring guide before attaching an adapter. The adapter must not inject another
chain supply. The script does not alter interface configuration or flash hardware.

```sh
python3 tools/can_peer.py --interface can0
```

Open the gateway CDC console with DTR asserted, send `inventory`, then
`register 00112233445566778899aabbccddeeff` and `apply`. The peer announces its UID
and profile, obtains an application route/lease and sends neutral input every
10 ms. Its actual Cyphal CAN node ID is independent of that route. Registration
reconnects gateway USB; reopen CDC if its port name changes. Restart with the same
identity to exercise nonzero input:

```sh
python3 tools/can_peer.py --interface can0 --buttons-mask 0x5 --axis-values 0x1234,0xffff
```

Use `--hats 4 --hat-values 0,7,8,8` for packed hats and `--show-acks` to print
reports acknowledged after successful host USB delivery. Maximum profiles support
`--buttons 128 --hats 4 --axes 8`. Each peer needs a unique `--identity`.

A new random boot session revokes the old lease. Stopping restores neutral HID
values after the gateway's 250 ms input timeout while preserving the registry
slot and USB layout. `--direct-usb` publishes ownership Status instead of Input
and leaves the gateway report neutral. SocketCAN backpressure retains the queued
frame for retry; expired frames are discarded using transport deadlines. Sequences
advance only after transport admission. Assignment and InputAck source checks
bind the peer to its current gateway until the presence timeout. Local CAN node-ID
migration purges queued frames and obtains a fresh application lease.

Native peer tests exercise all five message types, maximum profiles, source
metadata, duplicate transfer suppression, both frame formats, queue reset, SocketCAN retry
bytes and fresh Cockpit snapshots. Physical SocketCAN and assembled gateway tests
remain pending; no CAN adapter is connected in this workspace.

## JLCPCB fabrication and assembly files

```sh
sh tools/bundle-jlcpcb.sh                  # highest numeric board version
sh tools/bundle-jlcpcb.sh 0.1.0            # explicit version
sh tools/bundle-jlcpcb.sh --smd-only       # SMD assembly only
sh tools/bundle-jlcpcb.sh 0.1.0 --output-dir ../.research/jlcpcb-custom
```

Requires Python 3 and KiCad 10 on PATH; use `--kicad-cli /path/to/kicad-cli` for another installation. Calls work from any directory. Default output is workspace `.research/jlcpcb/`, with `gateway-<version>-gerbers.zip`, `gateway-<version>-bom.csv` and `gateway-<version>-cpl.csv`. SMD-only output adds `-smd` before the suffix. All files are regenerated from saved CAD; no prior export folder is needed. Temporary work stays in the output directory and is removed on exit.

Upload the Gerber ZIP for fabrication and the two CSVs separately for assembly. The BOM includes populated through-hole parts unless `--smd-only` is supplied. Mounting holes, DNP and BOM/position exclusions are omitted; both CSVs contain the same references. Blank JLCPCB catalog numbers must be matched using the exact manufacturer part number. Add schematic fields `LCSC` or `JLCPCB` with a `C<number>` identifier for explicit catalog selection. Component-specific rotation corrections are not guessed: check polarity, pin 1 and orientation in the assembly preview.

The script exports the saved filled board without changing it. Run the board’s ERC/DRC/parity checks and review [fabrication requirements](../electronics/boards/gateway/0.1.0/FABRICATION.md) before ordering, including the four-layer stackup and USB impedance specification.

Run converter/version-selection checks with `python3 -m unittest discover -s tools -p 'test_jlcpcb.py'`.

Other PCB tools now live here too. Run `sh tools/check-and-export.sh [version]` from any directory to refresh the board review exports (defaults to the highest numeric version). `audit-netlist.py` and `install-4p4c-footprint.py` retain their 0.1.0 gateway defaults; the audit accepts explicit `--netlist`/`--bom` paths. `write-manifest.py --version 0.1.0` refreshes source/export hashes and defaults to the highest numeric version.
