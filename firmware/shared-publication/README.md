The publication helper is an unmodified portable copy of
`include/opensimgear/publication.h` and `src/publication/publication.c` from
opensimgear/firmware-common at `b76fa216c5a48299139de7ffb1b41817d91a219b`.
It is vendored so standalone native gateway builds do not fetch MCU/USB
dependencies. Product policy belongs in `src/gateway_publication.c`.
